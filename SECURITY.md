# Security

The most recent public beta is the supported prerelease. Treat local logs and exported reports as sensitive. They can contain source paths and diagnostic text. Diffault analyzes logs on the device and calls GitHub only when you request an update check or open a GitHub link.

Report security issues through [GitHub private vulnerability reporting](https://github.com/zaanw/Diffault/security/advisories/new) when it is available. If private reporting is disabled, open a short issue asking for a private contact channel without including the vulnerability, proof of concept, logs or secrets.

Please include the affected version, impact and minimal safe reproduction in the private report. Redact project paths, tokens and account information. Use the [Bug Report template](https://github.com/zaanw/Diffault/issues/new?template=bug_report.yml) for ordinary application defects.
